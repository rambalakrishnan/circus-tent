# .omp-spec.md — config module

## Purpose

Loads all configuration files and resolves environment references. The ONLY module
allowed to read `config/*.yaml` and process env vars. Secrets are resolved at runtime
by name and never returned in repr/logs; no secret value is ever written to disk by
this module.

## Files

- `src/circus_tent/config/loader.py`
- `src/circus_tent/config/__init__.py` (exists)
- `tests/unit/test_config_loader.py`

class ConfigLoader:
    def __init__(self, config_dir: Path | str, env: Mapping[str, str] | None = None) -> None
    def resolve_env(self, value: str) -> str            # ${VAR} / ${VAR:-default}; raise ConfigError on missing

    def load_shards(self) -> tuple[ShardConfig, ...]
    def load_models(self) -> ModelsConfig
    def load_accounts(self) -> tuple[AccountConfig, ...]
    def load_callers(self) -> tuple[CallerConfig, ...]

## Behavior rules

1. `env` defaults to `os.environ`; passing an explicit mapping (tests) must never leak
   into `os.environ`.
2. `resolve_env` supports `${VAR}` and `${VAR:-default}`. Unresolvable → ConfigError.
3. `resolve_secret` returns the value; empty/whitespace-only → ConfigError naming the var.
4. Profile dirs are expanded (`~` → home) and returned absolute.
5. `shard_for_domain`: first pattern matching in declaration order wins. Pattern
   matching: exact match, or glob `*` at start (`*.workdayjobs.com` = subdomain of
   workdayjobs.com, not the apex), or bare `*`. The last shard must be `misc` matching
   `*` — validate and raise ConfigError otherwise.
6. Config files are plain YAML with `schema_version: 1`; any other version → ConfigError.
7. Unknown keys in config files → ConfigError (strict parsing catches typos).
8. Loading `.env` is NOT this module's job (done once at CLI/app startup via
   `dotenv`-style parse; export `load_env_file(path: Path) -> None` helper that loads
   ONLY variables not already present in os.environ).

## Edge cases

- Duplicate shard names → ConfigError.
- `profiles_root` missing/empty → ConfigError.
- shards list empty → ConfigError.
- Quota <= 0 → ConfigError.

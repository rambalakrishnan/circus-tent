# .omp-spec.md — browser module (shards, fingerprints, cluster, rate limiting)

## Purpose

Isolated Camoufox shard lifecycle: pinned fingerprint manifests, persistent profiles,
tab semaphores, health checks, drain/recycle with profile-safe flush ordering, and the
target-side rate limiter (B6). One browser process per shard, ≤ max_tabs concurrent
tab contexts, immutable fingerprints per profile.

def resolve_manifest(profile_dir: Path, launch_options: dict[str, Any]) -> FingerprintManifest
# creates {profile_dir}/fingerprint.json if absent (immutable afterwards);
# if present, loads and returns it — silently IGNORING the passed options.

def fingerprint_matches(manifest: FingerprintManifest, profile_dir: Path) -> bool
# manifest hash == hash of on-disk manifest; raises FileNotFoundError if absent

# page.evaluate script returning JSON {canvas, webgl, audio, navigator, screen, fonts}:
# canvas/webgl: FNV-1a hash of toDataURL pixels; audio: hash of OfflineAudioContext

# screen: {width, height, colorDepth}; fonts: sorted first-40 of document.fonts.check
# against a fixed probe list. Deterministic across runs for the same profile.

async def capture_fingerprint(page: Any) -> dict[str, Any]   # evaluate FINGERPRINT_JS, parse JSON

### shard.py

```python
class ShardState(str, Enum): INITIALIZING = "initializing"; READY = "ready"; DRAINING = "draining"; TERMINATED = "terminated"

@dataclass
class TabContext:
    context: Any          # playwright BrowserContext
    page: Any             # playwright Page (about:blank at issue time)
    issued_at: float      # time.monotonic()
    session_key: str | None = None

@dataclass
class ShardHealth:
    name: str; state: ShardState; tabs_active: int; pages_processed: int
    fingerprint_ok: bool; pid: int | None; cooldown_until: float | None
    last_error: str | None

class Shard:
    name: str; config: ShardConfig; profile_dir: Path
    def __init__(self, config, profile_dir: Path, metrics: Metrics, logger: logging.Logger)
    @property
    def state(self) -> ShardState
    @property
    def needs_recycle(self) -> bool          # pages_processed >= recycle_after_pages
    async def initialize(self, headless_override: str | None = None) -> None
    # INITIALIZING: mkdir 0700 profile dir + user_data; resolve/create manifest;
    # launch camoufox persistent context with manifest options; set READY.
    # Concurrency guard: two concurrent initialize() calls → second awaits first.
    async def health_check(self) -> bool     # about:blank responds + capture_fingerprint
                                             # equals manifest snapshot stored at init
    async def acquire(self, session_key: str | None = None) -> TabContext
    # waits on the shard's asyncio.Semaphore(max_tabs); new context + about:blank page
    async def release(self, tc: TabContext) -> None   # close context, release semaphore
    async def drain(self, grace_seconds: float) -> None   # DRAINING: wait in-flight ≤ grace
    async def flush(self) -> None            # close every context explicitly (storage flush)
    async def terminate(self) -> None        # close browser, wait PID exit ≤ 30s, TERMINATED
    def increment_pages(self, n: int = 1) -> None
    def snapshot(self) -> ShardHealth
```

class BackoffState:

### cluster_manager.py

```python
@dataclass
class ShardSnapshot:
    health: ShardHealth; config_name: str; patterns: tuple[str, ...]

class ClusterManager:
    def __init__(self, loader: ConfigLoader, metrics: Metrics, logger: logging.Logger) -> None
    async def start(self, warmup: bool = False) -> None
    # registers all shards (lazy); warmup=True initializes each (used by `serve --warmup`)
    def shard_for_domain(self, domain: str) -> Shard
    # routes via loader.shard_for_domain; lazy-initializes the shard on first use
    async def run_tab(self, domain: str, session_key: str | None,
                      task: Callable[[TabContext], Awaitable[T]]) -> T
    # acquire → task → release/finally; wraps rate_limiter.before_request(session_key)
    # and calls increment_pages() once per completed task
    async def recycle(self, shard_name: str) -> Shard
    # full sequence per ARCHITECTURE §5.3: drain → flush → wait PID exit → relaunch
    # from SAME profile dir with SAME manifest → health check → swap registry ref.
    # Raises ShardError if health check fails after N=2 attempts.
    def snapshots(self) -> list[ShardSnapshot]
    async def shutdown(self, drain_seconds: float = 30.0) -> int
    # 0 = clean drain of all shards; 1 = forced. Persists health.json per shard.
    def emit_event(self, event: str, **data) -> None   # logger JSON event (e.g. shard_recycled)
```

## VERIFIED API NOTES (camoufox 0.5.7 — do not regress)

Verified by live launch on this host (3 launches, zero fingerprint drift):

1. `AsyncCamoufox(**options)` is an **async context manager**, NOT a context
   object. `_launch(options)` returns the CM; `_enter(cm)` awaits
   `cm.__aenter__()` and yields the persistent `BrowserContext`. Teardown is
   `await cm.__aexit__(None, None, None)` after `await ctx.close()` (Shard.flush).
2. `user_data_dir` is only honored with `persistent_context: True` in the option
   dict. Without it camoufox calls `BrowserType.launch()`, which raises
   `TypeError: unexpected keyword argument 'user_data_dir'`.
3. **Pinning the launch flags is not enough for §5.2.** Left alone, camoufox
   randomises the OS and the WebGL vendor/renderer on EVERY launch (observed:
   webgl hash changed every launch; launch 3 switched from Windows to macOS,
   changing navigator + screen). The manifest must therefore persist the
   *generated identity*: call `camoufox.fingerprints.generate_fingerprint(
   window=(1440,900), os=os_name)` ONCE, store the returned dict plus the chosen
   `os` in the manifest, and pass `fingerprint=<dict>` + `os=<os_name>` +
   `i_know_what_im_doing=True` (camoufox warns otherwise) on every later launch.
   `build_launch_options(profile_dir, headless, humanize=True, fingerprint=None,
   os_name="windows")` does exactly this; two calls with `fingerprint=None`
   intentionally differ (fresh bundle each call) — pass an explicit dict for
   equality assertions in tests.
4. `headless="virtual"` is supported and camoufox wires its own virtual display
   (Xvfb present on this host; DISPLAY :99 detected).

## Behavior rules (binding)

1. **Fingerprint immutability**: `resolve_manifest` never overwrites an existing
   manifest. `Shard.initialize` passes the manifest options on EVERY launch. No
   random jitter anywhere in launch options. Changing a fingerprint requires the
   operator to delete the profile dir (bootstrap CLI documents this).
2. **Profile-safe recycle ordering** (amendment): drain → flush contexts → terminate
   browser → **wait for process exit** (poll `browser.process` / Popen.wait ≤30s) →
   THEN launch replacement from the same `user_data` dir. Never copy/snapshot
   `user_data/` while a browser is alive; never launch two browsers on one profile dir.
3. **Headless modes**: `initialize(headless_override=None)` uses config value.
   bootstrap passes `"false"`; production runs `"virtual"`. Values normalized:
   "virtual"→"virtual", "true"→True, "false"→False.
4. **Semaphore**: `asyncio.Semaphore(max_tabs)` created at init; acquire releases on
   context close even on exceptions (finally path in `run_tab`).
5. **Rate limiter placement**: `run_tab` calls `before_request` BEFORE acquire; a
   RateLimited raise surfaces as 429 with Retry-After at the API layer.
   `on_response` is called by the execution engine after each navigation/request
   completes (the engine owns the page; it reports status back via
   `cluster.report_response(domain, status, is_challenge)`).
6. Shard health: `health_check()` verifies the page responds AND
   `capture_fingerprint` equals the snapshot stored in memory at init
   (compare_fingerprints == []). Failure → last_error set, fingerprint_ok False.
7. `health.json` per shard: last state, timestamp, pid — written on shutdown and
   recycle. Never contains cookie data or launch secrets.
8. Events: `shard_recycled {old_pid,new_pid,pages,elapsed_ms}` via emit_event.

## Camoufox specifics (verify against pinned 0.5.7 at build)

- Import: `from camoufox.sync_api import Camoufox` is the sync API; for asyncio use
  `from camoufox.async_api import AsyncCamoufox` with `await AsyncCamoufox(...)` — the
  returned object is a Playwright BrowserContext-compatible wrapper
  (`launch_options` are passed to `launch_persistent_context`). The implementation
  must confirm the exact constructor signature for 0.5.7 at build time and pin the
  call shape in a module constant with a comment citing the version.
- If `AsyncCamoufox` is unavailable in the pinned version, run the browser in a
  dedicated thread with the sync API and bridge via `asyncio.to_thread` — document the
  choice. (Deterministic behavior beats API convenience; single-runtime principle
  still holds — one Python process, no sidecar.)

# .omp-spec.md — llm module (model conduit + budgets)

## Purpose

The ONLY module that makes LLM calls: LiteLLM conduit with provider failover, strict
JSON contracts with programmatic repair, and the token-budget/circuit-breaker engine
(B9). Lives in `src/circus_tent/engine/`.

## Files

- `src/circus_tent/engine/models.py`
- `src/circus_tent/engine/budgets.py`
- `tests/unit/test_models.py`, `tests/unit/test_budgets.py`

## Public API (keep signatures exact)

### models.py

```python
@dataclass(frozen=True)
class HealResponse:
    selector: str | None
    strategy: str | None          # "css" | "xpath" | None
    confidence: float
    reason: str

@dataclass(frozen=True)
class VisionResponse:
    x: int | None; y: int | None; width: int | None; height: int | None
    confidence: float

class ModelError(Exception): ...

class ModelClient:
    def __init__(self, cfg: ModelsConfig, metrics: Metrics, budgets: BudgetManager,
                 logger: logging.Logger) -> None
    async def heal(self, pruned_dom: str, fallback_text: str,
                   failed_selector: str) -> HealResponse
    async def locate(self, image_b64: str, fallback_text: str) -> VisionResponse
    def repair_json(self, raw: str) -> dict | None
    def build_headers(self, run_id: str) -> dict[str, str]
```

### budgets.py

```python
class BudgetExceeded(Exception):
    role: str; scope: str          # "session" | "shard"

class BudgetManager:
    def __init__(self, cfg: BudgetsConfig, metrics: Metrics, logger: logging.Logger,
                 clock: Callable[[], float] = time.monotonic) -> None
    def check_and_charge(self, role: str, session_key: str, shard: str,
                         tokens_in: int, tokens_out: int) -> None
    # raises BudgetExceeded BEFORE the call if any cap would be crossed
    def record_step_outcome(self, shard: str, healed: bool) -> None
    # rolling-window step counter for the circuit breaker
    def circuit_open(self, shard: str) -> bool
    # healed_steps / total_steps in window > threshold → True for cb_cooldown_seconds
    def snapshot(self) -> dict            # per-scope remaining budget + breaker states
```

## Behavior rules

1. **LiteLLM conduit** (B9): all model calls go through litellm. For
   `chat_completions` formats use `litellm.acompletion`; for `responses` formats use
   litellm's Responses-API path (`litellm.aresponses`) — verify availability against
   the installed litellm at build time; if unavailable, fall back to httpx POST with
   the same request shape and feed litellm's token counter for accounting. Document
   the choice in the module docstring.
2. **Provider failover** (C): iterate `role.providers` in order; timeout or 5xx →
   next provider; all failed → ModelError.
3. **Headers** (OpenCode Go requirements): every request carries
   `User-Agent: <cfg.user_agent>` and `<cfg.session_header_name>: <run_id>`
   (a stable UUID per run/conversation), plus `Authorization: Bearer <key>`.
4. **Key resolution**: `cfg.providers[i].api_key_env` → resolved at call time from
   process env (never cached in the object beyond the name).
5. **JSON contract + repair** (B5 decision): parse the model's text as JSON; on
   failure run `repair_json` (llm-json-repair first, then partial-json-parser for
   truncated streams); only then re-request (max 1 retry) with an explicit
   "return ONLY JSON" instruction appended; still bad → ModelError.
6. **Heal prompt**: format `cfg.heal_prompt` with `{fallback_text}`,
   `{failed_selector}`, `{pruned_dom}`. Vision prompt: `cfg.vision_prompt` with
   `{fallback_text}`; image sent inline as a data URL in a user message part.
7. **Budgets**: `check_and_charge` must be called before every call; tokens charged
   from litellm's reported usage (or estimated via litellm token_counter when the
   provider doesn't report). Budgets reset on UTC-day rollover (key includes the date).
   Circuit breaker: `circuit_open(shard)` consults the rolling window of
   `record_step_outcome`; open → the engine skips Tier 2 entirely (Tier 1 failure →
   Tier 3 → step failure). Metrics emitted for every charge (labels shard, role, model).
8. No LLM call may originate outside this module. Everything else raises ModelError
   to the engine, which converts to step statuses — never a server crash.

## Edge cases

- pruned_dom > 40KB chars → truncate head+tail to 40KB with a marker (HEAL budget
  is 50KB minus prompt overhead).
- image_b64 > ~2MB → downscale via PIL (max edge 1280) before sending.
- Empty providers list for a role → ModelError at construction (validate in loader).
- Budgets: unknown shard/session keys are auto-created (first charge).

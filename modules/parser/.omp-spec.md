# .omp-spec.md — parser module (SPA stabilization, pruning, extraction)

## Purpose

SPA stabilization, in-browser DOM pruning (two profiles), Shadow-DOM + frame
flattening, and the in-process Crawl4AI extraction pipeline with deterministic
schema-guided output. No LLM calls in this module, ever.

## Files

- `src/circus_tent/parser/trimmer.py`
- `src/circus_tent/parser/extraction.py`
- `src/circus_tent/parser/__init__.py` (exists)
- `tests/unit/test_trimmer.py`, `tests/unit/test_extraction.py`

## Public API (keep signatures exact)

### trimmer.py

```python
PruneProfile = Literal["EXTRACT", "HEAL"]

@dataclass(frozen=True)
class StabilizationResult:
    ok: bool                 # all conditions met
    partial: bool            # timed out with warning
    waited_ms: int
    missing_signatures: tuple[str, ...]

async def wait_for_stability(
    page: Any,
    signatures: Sequence[str] | None = None,   # core text signatures (title/heading)
    network_idle_ms: int = 500,
    dom_quiet_ms: int = 300,
    timeout_ms: int = 15000,
) -> StabilizationResult
# Condition 1: no in-flight requests for network_idle_ms (count via CDP
# request/response listeners started BEFORE this call).
# Condition 2: no mutations for dom_quiet_ms (MutationObserver installed via
# page.evaluate; poll a serialized quietness flag).
# Condition 3: all signatures present in document.body.innerText.
# Timeout → partial=True with which conditions failed.

PRUNE_JS_EXTRACT: str
PRUNE_JS_HEAL: str
# In-browser pruning scripts (constants). EXTRACT ≤250KB target, HEAL ≤50KB.
# Both MUST (amendment §5.4):
#  - shallow-clone via document.documentElement.cloneNode(true)
#  - remove script/style/noscript/iframe/link/meta
#  - img/svg → inline markers preserving semantics: [ICON:<aria-label|alt|title|role>],
#    buttons with role → [BUTTON:<label|role|text>]
#  - RECURSIVE shadow-DOM uncloaking: any element with .shadowRoot gets its rendered
#    children inlined (cloneNode does not see them; traverse explicitly)
#  - preserve aria-label, role, title, alt on retained elements
#  - collapse whitespace, drop empty text nodes, minify
# HEAL additionally: strip layout-only divs/span wrappers (no attrs, single text
# child → unwrap), collapse nested wrappers, keep only interactive + textual nodes.
# NOTE: frame flattening is NOT in the JS (frames are separate JS worlds) — see
# prune_page.

async def prune_page(page: Any, profile: PruneProfile = "EXTRACT") -> str
# Runs prune JS in the MAIN frame, then iterates page.frames() EXCLUDING the main
# frame: for each frame, evaluate the same script inside it (best effort; frames that
# throw or are unreadable contribute "[FRAME:<src>]"); concatenates:
# "MAIN:\n<pruned>\nFRAME <url>:\n<pruned>\n...". Returns the unified string.

async def prune_html(html: str, profile: PruneProfile = "EXTRACT") -> str
# Off-browser fallback for fixtures/tests: stdlib html.parser-based traversal with the
# same strip/inline-marker rules (no shadow DOM possible; no frames). Deterministic.
```

### extraction.py

```python
@dataclass(frozen=True)
class ExtractionResult:
    markdown: str
    structured: Any | None        # dict/list when schema supplied and satisfied
    schema_incomplete: bool
    stabilization: StabilizationResult | None

async def extract_page(
    page: Any,
    query: str | None = None,
    schema: dict | None = None,
    profile: PruneProfile = "EXTRACT",
    signatures: Sequence[str] | None = None,
) -> ExtractionResult
# wait_for_stability → prune_page(profile) → prune_html-style pipeline on the string
# via crawl4ai → optional schema_guided_extract.

async def extract_html(
    html: str,
    query: str | None = None,
    schema: dict | None = None,
) -> tuple[str, Any | None, bool]
# In-process Crawl4AI: BM25ContentFilter(user_query=query, bm25_threshold=1.2) when
# query given else PruningContentFilter(threshold=0.4); DefaultMarkdownGenerator;
# CrawlerRunConfig(cache_mode="BYPASS"); AsyncWebCrawler().arun(html=html, ...).
# Returns (markdown, structured, schema_incomplete).

async def batch_extract_html(
    items: Sequence[tuple[str, str | None]], max_concurrency: int = 8
) -> list[tuple[str, Any | None, bool]]
# MemoryAdaptiveDispatcher from crawl4ai, honoring max_concurrency; same filter logic.

def schema_guided_extract(markdown: str, schema: dict) -> tuple[Any | None, bool]
# DETERMINISTIC only. Heuristics over markdown structure (headings, lists, tables,
# key:value lines) validated against the JSON schema with jsonschema. Never calls an
# LLM. Unsatisfiable → (best-effort partial, schema_incomplete=True).
```

## Behavior rules

1. crawl4ai is imported lazily inside functions (heavy import; keeps unit tests fast).
2. Filter choice: query present AND non-empty → BM25; else Pruning. No other branches.
3. `schema_guided_extract` handles the common shapes: top-level object with
   string/number/array-of-string fields, arrays of uniform objects. Anything exotic →
   best-effort + schema_incomplete.
4. Extraction errors never propagate as 500s: engine maps them to step-level failures.
5. Determinism: no randomness, no time-dependence beyond the stabilization window.
   Unit tests for extraction use fixtures, not live pages.

## Edge cases

- Empty DOM (`about:blank`) → pruned output is a single newline; extraction returns
  empty markdown.
- Frames with cross-origin restrictions: page.frames() may raise on evaluate → catch
  per frame, emit `[FRAME:<src>]` marker, continue.
- Schema is not a valid JSON Schema → jsonschema raises → return (None, True).

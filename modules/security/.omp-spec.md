# .omp-spec.md — security module (challenge resolution)

## Purpose

CapSolver integration: challenge detection on target pages, task creation/polling,
token injection, per-session solve caching, and solve budgeting. All task types ship
enabled (operator decision). No secrets on disk; key resolved from env at runtime.

## Files

- `src/circus_tent/security/challenge_resolver.py`
- `src/circus_tent/security/__init__.py` (exists)
- `tests/unit/test_challenge_resolver.py`

## Public API (keep signatures exact)

```python
@dataclass(frozen=True)
class Challenge:
    type: str            # recaptcha_v2 | recaptcha_v3 | hcaptcha | funcaptcha |
                         # turnstile | datadome | geetest | imperva | akamai | perimeterx
    sitekey: str | None
    url: str             # page url where detected

@dataclass(frozen=True)
class SolveResult:
    task_id: str
    token: str | None            # g-recaptcha-response / h-captcha-response / turnstile
    cookie_name: str | None      # e.g. datadome
    cookie_value: str | None

class ChallengeDetector:
    # pure DOM-signature detection; no network
    def detect(self, pruned_dom: str, url: str) -> Challenge | None

class CapSolverClient:
    def __init__(self, api_key: str, metrics: Metrics, logger: logging.Logger,
                 poll_interval: float = 2.0, timeout: float = 120.0,
                 max_concurrent: int = 2) -> None
    async def solve(self, challenge: Challenge) -> SolveResult
    # POST api.capsolver.com/createTask (type mapped per challenge.type; ProxyLess
    # variants; websiteURL=challenge.url; websiteKey=sitekey) → poll
    # /getTaskResult until ready. 429/ERROR_RATE_LIMIT → backoff + retry (max 3).
    # Serialized by an asyncio.Semaphore(max_concurrent). Raises CapSolverError.
    async def inject(self, page: Any, challenge: Challenge, result: SolveResult) -> None
    # per type: set token into the right input/global (g-recaptcha-response,
    # h-captcha-response, cf-turnstile-response via page.evaluate) then dispatch
    # the site's callback hook if detectable; cookie types → context.add_cookies.

class ChallengeResolver:
    def __init__(self, client: CapSolverClient, metrics: Metrics, logger: logging.Logger,
                 max_solves_per_shard_day: int = 100) -> None
    async def handle(self, page: Any, pruned_dom: str, url: str, shard: str) -> bool
    # detect → if None: False (not a challenge). Solve-budget check (per-shard
    # daily cap) → cached per (shard, type, sitekey)? cached session tokens:
    # skip solve, reuse cached SolveResult (session-scoped in-memory cache).
    # solve → inject → True. Errors logged + counted, returns False (caller
    # proceeds as normal navigation failure).
    def snapshot(self) -> dict    # daily solve counts per shard, cache hits
```

## Task-type mapping (createTask bodies)

| challenge.type | CapSolver task type |
|---|---|
| recaptcha_v2 | ReCaptchaV2TaskProxyLess |
| recaptcha_v3 | ReCaptchaV3TaskProxyLess (minScore 0.9 requested, accept ≥0.7) |
| hcaptcha | HCaptchaTaskProxyLess |
| funcaptcha | FunCaptchaTaskProxyLess |
| turnstile | AntiTurnstileTaskProxyLess |
| datadome | DataDomeTask (+proxy required — report unsupported cleanly if no proxy configured) |
| geetest | GeeTestTask (needs gt/challenge params — detected from page data if present) |
| imperva | ImpervaTask |
| akamai | AkamaiBMPTask |
| perimeterx | PerimeterXTask |

Tasks needing proxy params that we don't configure (DataDome/GeeTest edge params)
must raise a descriptive CapSolverError, never a silent no-op.

## Behavior rules

1. Detection is DOM-signature based (grecaptcha badge, h-captcha iframe, Arkose
   funcaptcha iframe, turnstile div, datadome cookie meta, geetest div, imperva/akamai
   markers). Pure function of pruned DOM text → unit-testable.
2. Solve budget: per-shard daily cap (default 100) via the same pattern as the llm
   budgets module (UTC-day keys). Over cap → log + metric + return False.
3. Session solve cache: per (shard, type, sitekey) in-memory; a solved token is
   re-injected, not re-solved (cost discipline — see docs/external/capsolver.md).
4. Injection order: token into page state FIRST, then submit-triggering callback.
5. Never raise into the engine: `handle` returns bool; internal failures are logged
   with traceback at debug level.

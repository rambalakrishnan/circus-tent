# .omp-spec.md — telemetry module

## Purpose

Structured JSON logs, Prometheus metrics, OpenTelemetry spans with W3C traceparent
propagation, and secret redaction. Single file, imported everywhere; must never block
or raise on the hot path.

## Files

- `src/circus_tent/telemetry.py`
- `tests/unit/test_telemetry.py`

## Public API (keep signatures exact)

```python
class SecretRedactor:
    def __init__(self, extra_patterns: Sequence[str] | None = None) -> None
    def redact(self, text: str) -> str

def setup_logging(level: str = "INFO") -> None      # JSON lines via logging; idempotent
def get_logger(name: str) -> logging.Logger

class Metrics:
    tabs_active: prometheus_client.Gauge          # labels: shard
    queue_depth: prometheus_client.Gauge          # labels: shard
    permit_wait_seconds: prometheus_client.Histogram  # labels: shard
    tokens_consumed: prometheus_client.Counter    # labels: shard, role, model
    heal_attempts: prometheus_client.Counter      # labels: shard, outcome
    vision_attempts: prometheus_client.Counter    # labels: shard, outcome
    circuit_breaker_state: prometheus_client.Gauge  # labels: shard (0 closed, 1 open)
    callback_failures: prometheus_client.Counter
    audit_events: prometheus_client.Counter
    pages_processed: prometheus_client.Counter    # labels: shard
    http_requests: prometheus_client.Counter      # labels: method, path, status

def get_metrics() -> Metrics                       # singleton
def metrics_text() -> str                          # prometheus text format
def start_span(name: str, attributes: dict | None = None) -> contextlib.AbstractContextManager  # OTel span
def current_traceparent() -> str | None            # "00-<trace>-<span>-01" or None
def traceparent_from(headers: Mapping[str, str]) -> str | None  # honors inbound W3C traceparent
```

## Behavior rules

1. `setup_logging` installs a JSON formatter (ts ISO8601 UTC, level, logger, event,
   plus extra fields passed via `extra={"k": v}`). Values pass through a module-level
   `SecretRedactor` before serialization. Calling it twice must not duplicate handlers.
2. Redaction patterns (case-sensitive):
   - `sk-` + ≥20 alphanumeric (OpenAI-style keys)
   - Bearer token values after `Authorization`
   - anything matching `[A-Za-z0-9_-]{24,}` that equals a value loaded from env vars
     whose names match `SECRET|KEY|TOKEN|PASSWORD` (module registers them via
     `SecretRedactor.register_secret(value)`; caller side: a `redact_secret` helper in
     setup_logging scans os.environ once).
   - Redacted output: `***REDACTED***`.
3. OTel: no exporter is configured by default (console span processor at DEBUG only);
   `start_span` creates a child span of the current context and sets
   `trace_id/span_id` from the inbound `traceparent` when provided via
   `traceparent_from`. Never raise if OTel init fails (fall back to no-op spans).
4. Metrics singleton; `metrics_text()` returns `latest` exposition from the default
   registry (includes prometheus_client process/GC metrics).
5. The logging layer is the ONLY path secrets may be redacted on — other modules must
   pass sensitive values through `get_logger(...).info("...", extra={...})`, never
   f-strings into log calls with raw secrets.

## Edge cases

- `redact("")` → `""`; `redact(None)` → raises TypeError (typed: str in).
- `traceparent_from` with missing header → None; malformed → None (no raise).
- JSON serialization of log extras: non-serializable → `repr` fallback.

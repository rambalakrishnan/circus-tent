# .omp-spec.md — cli module

## Purpose

The `circus-tent` entry point: `serve` (ASGI app via uvicorn, graceful shutdown,
exit-code contract) and `bootstrap` (headful first-run MFA handoff per shard).

## Public API (keep signatures exact)

```python
# cli/main.py
def build_parser() -> argparse.ArgumentParser
def main(argv: Sequence[str] | None = None) -> int
# argparse subcommands:
#   circus-tent serve [--host 127.0.0.1] [--port 8000] [--config-dir ./config]
#                     [--warmup] [--log-level INFO]
#   circus-tent bootstrap --shard NAME [--config-dir ./config]
# return code: 0 clean shutdown; 1 forced drain / startup failure (B7 contract)

# cli/bootstrap.py
async def bootstrap_shard(shard_name: str, config_dir: Path,
                          logger: logging.Logger) -> int
# 1. Load shard config; resolve profile dir (0700).
# 2. Launch Camoufox headless=False (via the browser module's factory with
#    headless_override="false") — fingerprint manifest created on this first run.
# 3. Print instructions; navigate to the shard's preflight URL when set.
# 4. Block on operator confirmation (interactive input(): "Type 'done' and press
```

## Behavior rules

1. `serve` startup order: `load_env_file(config_dir / ".." / ".env")` (dev fallback,
   never overrides existing env) → setup_logging → create_app → uvicorn.run (uvloop
   standard extras). SIGTERM/SIGINT handled by uvicorn → app lifespan runs the
   graceful shutdown (B7: stop accepting → drain in-flight → flush contexts → close
   browsers → persist caches/ledger → exit code 0 clean / 1 forced).
2. `bootstrap` must refuse to run with `headless` profiles that would skip the
   operator interaction (always headful); refuses if the fingerprint manifest
   already exists UNLESS `--reset` is passed (purging profile + manifest = the only
   sanctioned fingerprint-change path — print a loud warning listing the lockout
   risk from ARCHITECTURE §5.2 and require typing "RESET" to confirm).
3. Never print env values or secrets; never write secrets to disk.
4. `main` catches ConfigError → stderr message + exit 2 (usage/config errors).
5. KeyboardInterrupt in bootstrap → still runs the flush sequence.

## Edge cases

- Unknown shard name → exit 2 with the list of valid shards.
- `--reset` without an existing manifest → proceeds as first-run.
- Headless environment (no DISPLAY): bootstrap requires a display; detect and
  explain (`$DISPLAY` unset and no Xvfb → run under xvfb-run; the host has Xvfb).

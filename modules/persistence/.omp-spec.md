# .omp-spec.md — persistence module (selector cache, coordinate cache, ledger)

## Purpose

Versioned on-disk stores: selector cache (self-healing), coordinate cache
(perceptual-hash → click box), and the execution ledger (idempotency + checkpoints).
All writes atomic (tmp file + rename); all files carry schema_version. Lives in
`src/circus_tent/engine/` (see AGENTS.md module index).

## Files

- `src/circus_tent/engine/selector_cache.py`
- `src/circus_tent/engine/coordinate_cache.py`
- `src/circus_tent/engine/ledger.py`
- `tests/unit/test_selector_cache.py`, `test_coordinate_cache.py`, `test_ledger.py`

## Public API (keep signatures exact)

### selector_cache.py

```python
@dataclass
class SelectorEntry:
    selector: str
    strategy: str                  # "css" | "xpath"
    confidence: float              # 0.0..1.0
    hit_count: int = 0
    heal_count: int = 0
    stale: bool = False
    fallback_text: str = ""
    last_verified: str = ""        # ISO8601

class SelectorCache:
    def __init__(self, path: Path, domain: str, prompt_version: int) -> None
    def load(self) -> None                     # missing file → empty cache (no error)
    def get(self, step_id: str) -> SelectorEntry | None   # non-stale preferred; stale returned only if no live entry
    def record_hit(self, step_id: str, now: str | None = None) -> None
    def record_heal(self, step_id: str, entry: SelectorEntry) -> None
    # confidence decremented by 0.05 (floor 0.1) on each heal; heal_count += 1
    def mark_stale(self, step_id: str) -> None
    def demote_by_prompt_version(self) -> None   # prompt bump: mark all stale=True
    def entries(self) -> dict[str, SelectorEntry]
    def save(self) -> None          # atomic: tmp + os.replace; schema_version 1
```

On-disk shape: `{domain, version: "2026.10", prompt_version, last_verified,
steps: {step_id: {selector, strategy, confidence, hit_count, heal_count, stale,
fallback_text, last_verified}}}`.

### coordinate_cache.py

```python
@dataclass
class CoordinateEntry:
    x: int; y: int; width: int; height: int
    viewport: tuple[int, int]
    step_id: str
    hit_count: int = 0
    created_at: str = ""

def compute_dhash(png_bytes: bytes, size: int = 16) -> str
# dHash: resize (size+1) x size grayscale via PIL; row-difference bits → hex string.
# Deterministic for identical pixels; robust to minor compression noise.

class CoordinateCache:
    def __init__(self, path: Path, domain: str) -> None
    def load(self) -> None
    def get(self, phash: str, viewport: tuple[int, int]) -> CoordinateEntry | None
    # hash match AND viewport match (dimensions) — different viewport = different coords
    def record(self, phash: str, entry: CoordinateEntry) -> None
    def save(self) -> None          # atomic; schema_version 1
```

On-disk shape: `{domain, entries: {<phash>: {x, y, width, height, viewport: [w,h],
step_id, hit_count, created_at}}}`.

### ledger.py

```python
@dataclass
class LedgerCheckpoint:
    step_id: str
    index: int                     # 0-based index in the step list
    note: str = ""
    created_at: str = ""

@dataclass
class LedgerRun:
    run_id: str
    idempotency_key: str
    account: str
    shard: str
    domain: str
    status: str                    # running | completed | failed
    step_states: dict[str, str]    # step_id → ok|healed|vision|failed|skipped
    checkpoints: list[LedgerCheckpoint]
    side_effect_completed: list[str]
    created_at: str
    updated_at: str

class ExecutionLedger:
    def __init__(self, base_dir: Path) -> None
    # base_dir = <profiles_root>/ledger (runtime state, gitignored, 0700)
    def get_by_key(self, idempotency_key: str) -> LedgerRun | None
    def create(self, run_id: str, idempotency_key: str, account: str, shard: str,
               domain: str, steps: Sequence[str]) -> LedgerRun
    # steps = ordered step ids; step_states pre-initialized to "pending"
    def record_step(self, run_id: str, step_id: str, status: str) -> None
    def record_checkpoint(self, run_id: str, step_id: str, index: int, note: str = "") -> None
    def mark_side_effect_done(self, run_id: str, step_id: str) -> None
    def finalize(self, run_id: str, status: str) -> None
    def last_checkpoint(self, run_id: str) -> LedgerCheckpoint | None
    def save(self, run_id: str) -> None   # atomic write of the run's JSON file
```

Storage: one JSON file per run, `{base_dir}/{sha256(idempotency_key)[:32]}.json`.
Concurrency: single asyncio loop; guard with an internal `asyncio.Lock` per key file.

## Behavior rules

1. All `save()` methods write to `path.with_suffix(".tmp")` then `os.replace` — a
   crash never leaves a truncated cache.
2. Loading a corrupt/old-schema file: log warning, back up to `.bak`, start empty
   (never crash the server).
3. `record_heal` decrements confidence by 0.05 per heal, floor 0.10, and sets
   `stale=False` (a healed selector is live again).
4. Ledger files are per-run runtime state — never committed (base_dir is under
   profiles_root; repo .gitignore covers `profiles/`).
5. Timestamps UTC ISO8601 with seconds precision.
6. No dependencies outside stdlib + pydantic-free plain dicts (keep it light;
   jsonschema not needed here).

## Edge cases

- `record_hit` on unknown step_id → no-op (do not raise).
- Two concurrent `save()` calls → last-writer-wins via the lock.
- `get_by_key` on a ledger dir that doesn't exist yet → None.
- dHash of a solid-color image is well-defined (zeros) — do not special-case.

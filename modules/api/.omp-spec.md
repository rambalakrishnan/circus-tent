## Public API (keep signatures exact)

### fairness.py

```python
class QueueTooDeep(Exception):
    depth: int; limit: int

class FairShare:
    def __init__(self, max_permits: int, default_quota: int = 3,
                 max_queue_depth: int = 1000,
                 clock: Callable[[], float] = time.monotonic) -> None
    async def acquire(self, key: str, quota: int | None = None) -> None
    # FIFO by arrival; a key holds at most its quota permits at once; waits until
    # a permit is free AND the key is under quota. Raises QueueTooDeep when the
    # waiting queue exceeds max_queue_depth at enqueue time.
    def release(self, key: str) -> None
    def queue_depth(self) -> int
    def wait_time_ms(self, key: str) -> float     # time in queue for key's oldest waiter
    def snapshot(self) -> dict                    # {holds, waiting, queue_depth, wait_ms}
```

Fairness property (acceptance #4): every waiting key eventually acquires (FIFO);
no key exceeds its quota; max wait bounded by queue length × per-task duration.

### callbacks.py

```python
class CallbackClient:
    def __init__(self, sign_key: str, metrics: Metrics,
                 logger: logging.Logger, max_retries: int = 3) -> None
    async def notify(self, callback_url: str, payload: dict,
                     traceparent: str | None = None) -> bool
    # POST json payload with headers X-Circus-Tent-Signature: sha256=<hex hmac
    # (sign_key, body)> and traceparent if given; retries with backoff (1s, 2s, 4s);
    # returns delivery status; failures increment metrics.callback_failures.
    # NEVER blocks the response: callers use asyncio.create_task with a bounded
    # background queue (max 100 pending).
```

### service.py

```python
class Service:                       # shared wiring for rest + mcp
    def __init__(self, config_dir: Path, env: Mapping[str, str] | None = None) -> None
    loader: ConfigLoader; cluster: ClusterManager; engine: ExecutionEngine
    fairness: dict[str, FairShare]   # per shard name (max_permits = shard max_tabs)
    auth: CallerAuth; audit: AuditLog; callbacks: CallbackClient
    async def start(self, warmup: bool = False) -> None
    async def shutdown(self, drain_seconds: float = 30.0) -> int
    async def run(self, caller: CallerConfig, req: dict) -> RunResult
    # audit.record(...) wrapper: engine.run + fairness.acquire/release around it,
    # caller rate check, scope check, callback fire-and-forget on terminal state
    async def extract(self, caller: CallerConfig, req: dict) -> ExtractionResult
    def health(self) -> dict
    def shards(self) -> dict
```

Fairness wiring: `Service.run` resolves the shard for the domain, then
`fairness[shard].acquire(account, quota)` BEFORE `cluster.run_tab` (Layer-2 quota on
top of Layer-1 shard semaphore). Back-pressure: on `QueueTooDeep` → HTTP 429 with
`Retry-After` + `X-Queue-Depth`; on queue wait, set both headers on the response.

### rest.py

FastAPI `APIRouter` with request/response pydantic models (see docs/contracts/api.md):

- `POST /run` → 200 RunResult envelope | 429 (back-pressure / caller rate) | 409
  IDEMPOTENCY_CONFLICT | 422 BAD_REQUEST (invalid steps).
- `POST /extract` → 200 | 429.
- `GET /health` → service.health().
- `GET /shards` → service.shards().
- `GET /metrics` → `metrics_text()` (plain text).
- Auth dependency: every route except /metrics? NO — /metrics also requires auth
  (it's caller-scoped data). Only nothing is unauthenticated: all routes require
  bearer (health too — it leaks topology). 401 shape per contract.
- Error handler: AuthError/IdempotencyConflict/QueueTooDeep/BudgetExceeded →
  structured error envelope with the right codes and headers.

## Behavior rules

1. No request is silently dropped: every response is 2xx, 4xx with explicit code, or
   5xx logged with trace_id (acceptance #7).
2. Secrets: caller keys are resolved by name at construction; constant-time compare
   (`hmac.compare_digest`); never logged.
3. CORS: disabled by default (same-host); no open CORS.
4. The audit log writes BEFORE the task runs (intent) and the status is updated in a
   second record on completion (outcome) — both bound by the same trace_id.
5. Callback delivery must never delay the HTTP response (bounded background queue).
